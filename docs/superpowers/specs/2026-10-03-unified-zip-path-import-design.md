# 统一的 ZIP 路径选择与导入设计

状态：已实现；APK 弹层已在真机验证；KernelSU WebUI 待重启激活模块更新后验收

本设计替换 `2026-09-24-gpu-driver-loading-v1-design.md` 中 WebUI 与平台桥接部分的文件选择和 ZIP 传输方式；其余驱动格式、校验、存储和加载约束保持不变。

## 目标

让 KernelSU WebUI 和独立 APK 使用同一套应用内 ZIP 浏览弹层和导入流程，去掉浏览器选中文件后经 Base64 分块传给 root 的旧路径，以及 APK 与 WebUI 各自不同的文件选择入口。弹层不提供系统文件选择器按钮。

## 用户流程

GPU 驱动页打开应用内弹层，默认进入 `/storage/emulated/0/Download`，可在 `/storage/emulated/0` 内浏览。目录排在 ZIP 文件前，只显示并允许选择扩展名不区分大小写的 `.zip` 文件。顶部路径按层级展示，可点击跳转；点击目录进入目录，点击 `..` 或使用系统返回键回到上一级。处于共享存储根目录时，系统返回键按取消关闭弹层。切换目录会清除先前选中的文件。

弹层底部提供“取消”和“导入”。未选 ZIP 时“导入”不可用。确认导入后关闭弹层，并复用驱动页现有的导入中和结果反馈。弹层只读，不提供删除、移动、重命名等文件操作。加载中、空目录、无权访问、带重试操作的错误状态和已选文件状态都需要清楚显示，并提供可访问性描述。

沿用现有 Miuix 视觉语言和动态主题。弹层限制宽高，文件列表区域单独滚动；文件名和路径作为纯文本展示，不解释为标记语言。

## 共享架构

- 选择器组件和交互状态放在 `commonMain`，APK 与 KernelSU WebUI 共用同一页面、状态和验证规则。
- 平台桥接只负责以结构化数据列出指定目录，并将所选 ZIP 路径交给同一个 root 侧导入入口；APK 和 WebUI 不各自解析、解压或校验驱动 ZIP。
- root 侧导入入口先将来源复制到模块私有的唯一暂存文件，再从该快照读取和校验，避免校验后来源文件被替换。
- 保持现有 AdrenoTools ZIP 契约：ZIP 根目录含 `meta.json` 和根目录驱动库，`meta.json.libraryName` 指定主库；保留原始库字节，不要求重打包或修改 SONAME。
- 沿用现有校验要求：安全的 ZIP 路径和条目类型、拒绝符号链接及重复路径、`meta.json` 与 `libraryName`、大小和条目数上限、CRC、SHA-256，以及 arm64 little-endian `ET_DYN` ELF 主库校验。
- 通过现有仓库变更锁检查重复驱动并发布完整目录和索引。已安装驱动 ID、目录布局及 App 绑定格式保持不变，现有驱动无需重新导入或重新绑定。

## 安全与失败行为

- 浏览根目录固定为 `/storage/emulated/0`。每次列目录和导入时都校验规范化路径仍位于该根目录下；拒绝路径穿越、越界符号链接和非普通 ZIP 文件。
- 路径和文件名均为不可信输入。shell 参数必须按参数数据安全传递，不能拼成可执行 shell 片段；目录项返回值使用明确的结构化编码，并拒绝传输或 UI 无法安全表示的控制字符。
- 禁止直接对不可信 ZIP 执行覆盖式整包解压。先检查归档记录，再仅提取通过校验的根目录文件到隔离且受大小限制的暂存目录。
- 对输入 ZIP 大小、条目数、元数据大小、库数量及总解压大小设上限，并在读取过程中再次执行限制。
- 取消时不执行 root 导入命令，也不报错。目录读取失败时显示可重试错误。导入失败时只清除本次快照和暂存内容，保留已有驱动索引、文件和 App 绑定。
- root 权限仍由当前 APK 或 KernelSU WebUI 宿主已有的授权控制。

## 不在本次范围内

不支持 Android Storage Access Framework、系统文件选择器、content URI、云文件提供方或任意 root 文件系统浏览；不增加通用文件管理能力。GitHub Release 下载来源复用现有 ZIP 校验与发布流程；下载文件使用私有目录中与操作 nonce 匹配的路径，通过 `prepare-download` 入口校验。在线仓库的用户操作见[使用指南](../../gpu-driver-guide.md#在线仓库与下载)。

## 验证

- common UI/state 测试覆盖目录边界、目录优先排序、ZIP 筛选、选择、取消、加载/空/错误状态和可访问性描述。
- 平台桥接测试覆盖空格与 Unicode 文件名、参数传递、非法控制字符、路径穿越、越界符号链接及非普通文件拒绝。
- 导入测试使用真实 ZIP：原始 AdrenoTools 包应保持驱动库字节不变并成功安装；路径穿越、符号链接、重复项、缺少元数据或库、嵌套库、CRC 错误、损坏 ZIP、错误 ABI/ELF、超限归档、重复驱动 ID 和发布失败均应拒绝。每个失败场景都确认索引、已安装驱动和绑定未改变。
- APK 与 KernelSU WebUI 验证共用同一个弹层和导入结果；覆盖内部存储浏览、取消、成功导入及失败反馈。
- 在 Adreno 测试手机上用同一份已缓存 Turnip ZIP 对比完整导入耗时；核对原始库 SHA-256、发布索引及后续 Unity 的 `Loaded` 映射和渲染结果。另验证恶意 ZIP 被拒绝且原有驱动哈希和绑定不变。
